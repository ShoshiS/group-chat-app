# Client

Angular 19 — standalone components, Signals, Reactive Forms, Angular Material.

## Setup

```bash
npm install
ng serve
```

## Structure

```
src/app/
├── core/          # auth, interceptors, guards
├── shared/        # buttons, cards, shared form
└── features/
    ├── auth/
    ├── groups/
    ├── invitations/
    └── chat/
```
